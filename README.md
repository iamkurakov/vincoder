# Terrain Drive: Open Roads (VinCoder)

Код игры для Unity 6 LTS (URP). Исходники — в `Assets/_Game`.

## Запуск
1. Создайте проект Unity 6 по шаблону Universal 3D.
2. Package Manager: установите Input System (на вопрос о перезапуске — Yes).
   Project Settings > Player > Active Input Handling = Input System Package (New) или Both.
3. Window > TextMeshPro > Import TMP Essential Resources.
4. Скопируйте папку `Assets/_Game` в папку `Assets` проекта (или откройте этот репозиторий как проект Unity).
5. После компиляции: меню **Terrain Drive > Собрать проект** (данные, префабы, сцены).
6. Откройте сцену `Assets/_Game/Scenes/Boot` и нажмите Play.
