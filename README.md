# Terrain Drive: Open Roads (VinCoder)

Браузерный автосимулятор. Играть: **https://iamkurakov.github.io/vincoder/**

Работает в любом современном браузере на компьютере и телефоне, установка не нужна.

## Что есть
- 6 зон: Тестовый полигон, Трасса, Город, Лес, Бездорожье, Открытый мир.
- 6 режимов: свободная езда, заезд на время, гонка по чекпоинтам, испытание бездорожьем, городское испытание, рывок по трассе.
- 5 машин (седан, внедорожник, пикап, ралли-кар, спорткар) с разным приводом и характеристиками, тюнинг, покраска, ремонт.
- Физика подвески и шин, 10 типов покрытия (асфальт, гравий, грязь, песок, трава, камни, вода…), повреждения, AI-трафик.
- Уровни, опыт, кредиты, рекорды и медали (сохраняются в браузере).

## Управление
| Клавиши | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз, задний ход |
| A D / ← → | руль |
| Пробел | ручник |
| R | вернуться на дорогу / к чекпоинту |
| C | камера |
| Esc / P | пауза |
| M | звук |

Поддерживаются геймпад и сенсорные кнопки на телефоне.

## Локальный запуск
```
python3 -m http.server 8000
```
и открыть http://localhost:8000.

## Структура
- `index.html`, `css/`, `js/` — браузерная игра (Three.js из `vendor/`).
- `Assets/_Game` — исходная версия для Unity 6 (URP). Чтобы собрать её, нужен редактор Unity: создайте проект по шаблону Universal 3D, установите Input System и TMP Essentials, скопируйте `_Game` в `Assets`, выполните меню **Terrain Drive > Собрать проект** и запустите сцену `Assets/_Game/Scenes/Boot`.
